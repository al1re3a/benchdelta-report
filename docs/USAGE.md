# راهنمای BenchDelta

## سناریوی عملی

مقایسهٔ خروجی Hyperfine و گزارش HTML آفلاین. مخاطب اصلی: نگه‌دارندهٔ CLI، کتابخانه و تیم کارایی.

از [شروع سریع](../README.md#quick-start) استفاده کنید. فرمان را از ریشهٔ همین ریپازیتوری اجرا کنید.

فایل `report.html` را در مرورگر باز کنید. مثال، build را ۲۵٪ کندتر و test را ۱۵٪ سریع‌تر نشان می‌دهد؛ خروج با کد ۱ در این مثال انتظار می‌رود. برای دادهٔ واقعی، ابتدا دو اجرای قابل‌مقایسهٔ Hyperfine را با `--export-json` ذخیره کنید.

## رفتار و خطاها

فقط میانگین زمان و نام command مقایسه می‌شود؛ اندازهٔ نمونه، confidence interval و معنی‌داری آماری محاسبه نمی‌شوند. شرایط ماشین و نام فرمان‌ها باید قابل‌مقایسه باشند. بودجهٔ منفی یا NaN، میانگین نامثبت و نام تکراری رد می‌شوند. هر ورودی حداکثر ۳۲ MiB؛ گزارش موجود بازنویسی نمی‌شود.

اگر اجرای نمونه شکست خورد، نسخهٔ runtime، فرمان، کد خروج و یک ورودی ساختگی کوچک را در issue ضمیمه کنید. فایل‌های output موجود را ابتدا با نام دیگری نگه دارید؛ ابزارهای دارای خروجی فایل از overwrite ناخواسته جلوگیری می‌کنند.

## مثال و تست

نمونه‌های کوچک در پوشهٔ [examples](../examples) قرار دارند؛ دادهٔ شخصی واقعی در آن‌ها نیست.

```bash
python -m unittest discover -s tests -v
node --test tests/report.test.cjs
```
